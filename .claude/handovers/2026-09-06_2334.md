## 決定事項

- 書き込みは `MetadataWritePort` の向こうへ置き、crowexif の `TagEdit` は
  `lib/adapters/crowexif_writer.dart` の中だけで作る（§7.1）。ドメインは中立の
  `TagWrite`（グループ・名前・値。値が null なら削除、名前が `*` ならグループごと削除）。
- 検証（FR-E6-3）は「正規化した撮影時刻と位置」で見る。読み直した表示値は書いた文字と
  同じとは限らない（列挙や単位が付く）ので、直接指定したタグは有無だけを見る。
- 形式ごと書けないのか、そのタグの置き場所が無いのかを分ける。形式は書き込みへ入る前に
  `canWriteMetadata` で弾く（`lib/domain/supported_formats.dart`）。動画は crowexif に
  ISO BMFF 書き込みが入るまで書けない。
- 座標は必ず半球の文字を添えて書く。crowexif は「半球が書かれている場合にのみ」
  Ref タグを書くので、`35.68 N` のように書かないと北緯・東経の Ref が入らない。
- 対象ごとに結果が変わる操作（連番配分、取り込み）が入ったので、計画に渡す材料を
  `EditTarget`（名前・更新時刻・撮影時刻・位置・並びの位置）へまとめた。
- 控えは既定でアプリ領域の `backups/`。原本のパスの SHA-256 の先頭 16 文字でフォルダを
  分け、その中に世代を残す。ユーザのフォルダを散らかさないため。
- 右パネルのどちらを出しているかは `sidePanelTabProvider` に持つ。画面の外
  （下部ナビゲーション、キャプチャの入口）からも同じ場所を開けるようにするため。

## 捨てた選択肢と理由

- 適用前の見通しを「タグごとの変更前後」で出す: 変更前のタグ値は要約に無く、全タグを
  読み直すことになる。SPEC FR-E5 が求めるのは「変更前後・対象件数・書き込み先タグ」
  なので、正規化した値の差分＋書き込み先タグの一覧で足りる。
- 見通しの時刻を短い表記（分まで）で出す: 秒だけずらす編集が見えない。秒まで出す。
- タグの行に常に鉛筆を出す: 380 px の幅にアイコンが 3 つ並んで窮屈になる。
  行を選んだときだけ出す。
- 度分秒の単位に `d` `m` `s` を認める: `35 40 52.4 S` の `S` が秒の単位として食われ、
  南半球にならなかった。記号と `deg` だけを認める。
- `MetadataWriteError` をすべて「書けない形式」に寄せる: crowexif は「この形式に
  このタグは入らない」も同じ例外で投げる。理由を 2 つに分けた。
- 一括書き込みを 1 件ずつ順に走らせる: 7 MB の JPEG 1,000 件で 60 秒（NFR-2 の限界）。
  走査と同じ並列数で回して 44 秒になった。

## ハマりどころ

- `TabController.index` を build の中で書き換えると、リスナーが同じフレームで走って
  「Tried to modify a provider while the widget tree was building」になる。
  写している最中だけ立てる旗で、書き戻しを止める。
- `tester.scrollUntilVisible` は、対象がすでにウィジェットツリーにあると 1 度も
  スクロールしない。パネルは全行を組み立てるので、画面の外にある行はそのまま
  タップできない。`tester.ensureVisible` を使う。
- `dart run` で `package:flutter/foundation.dart` を使うファイルは読めない。
  ベンチマークの類は `flutter run -t` か、flutter に依存しない形で書く。
- `dart format` は行を組み直すので、`python` で行番号を狙った置換をすると当たらない。
  置換したら必ず `grep` で入ったことを確かめる（前回の教訓の続き）。
- 走査直後の並びは、撮影時刻が同じファイルどうしで安定しない。連番配分の割り当て順を
  テストで固定するときは、見通し（`editPreviewProvider`）が返す順を読んでから比べる。

## 学び

- crowexif の `TagEntry.format` は記録形式の名前（`int16u` `string` `rational64u`）を
  持つ。直接編集の入力補助（数値か文字か）はこれで決められる。
- crowexif の `writeFile` は一時ファイルへ出して置換するところまでやる。
  アプリ側は控えと検証を足すだけでよい（FR-E6-1 はライブラリ側で満たされている）。
- crowexif に `TagEdit.delete('all', group: 'GPS')` を渡すと GPS グループごと消える。
  位置の削除（FR-E4-5）はこれ 1 つで足りる。
- 書き込み後は大きさと更新時刻が変わるので、対象キャッシュ（FR-B17）の有効性判定が
  自然に外れる。`LibraryNotifier.refresh` で読み直してキャッシュごと入れ替える。
