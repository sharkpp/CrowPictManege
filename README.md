# CrowPictManege

画像・動画のメタ情報を一覧・閲覧・編集するアプリケーション。
撮影時刻と GPS 情報の修正を容易にすることを中核とする。

仕様は [SPEC.md](SPEC.md) を参照。

## 構成

- Flutter / Dart。Windows・macOS・iOS・Android・Web を単一のコードベースで対象とする。
- メタ情報の読み書きは [crowexif](https://github.com/sharkpp/crowexif)（pure Dart）に一本化する。
  隣に置いた作業コピーを `path` 依存で参照する。

```
lib/
  domain/    I/O を持たない業務ロジック（時刻・GPS の正規化、編集操作と書き込み計画、
             列とフィルタ、フォルダ表示、検索の判定、知覚ハッシュ、設定の符号化）
  ports/     プラットフォームに依存しない抽象インタフェース（メタ情報の読み書き、カタログ）
  adapters/  ポートの実装（crowexif の読み取りと書き込み、ファイルシステム、
             SQLite のカタログ）
  services/  並列読み取り、サムネイルキャッシュ、検索、類似画像
  state/     画面の状態（Riverpod）
  ui/        画面
  l10n/      画面に出す言葉（日本語 / 英語の ARB と、そこから生成する取り出し口）
```

画面に出る言葉は `lib/l10n/app_ja.arb`（原本）と `lib/l10n/app_en.arb`（対訳）に置く。
言葉を足したら両方に入れ、次を実行して取り出し口を作り直す。

```console
$ flutter gen-l10n
```

カタログ（設定・ブックマーク・履歴・メタ情報とサムネイルのキャッシュ）は
アプリ領域の `catalog.sqlite` に置く。書き込みの前に取る原本の控えは、
既定でアプリ領域の `backups/` に置く（設定で場所と世代数を変えられる）。drift のテーブル定義から
`catalog_database.g.dart` を生成しているので、テーブルを変えたら次を実行する。

```console
$ dart run build_runner build
```

## いまできること

- フォルダを開く（ダイアログ、ドロップ、パンくず、履歴、ブックマーク）
- 表示モード: サムネイル／リスト／ギャラリー／マップ
- 下位フォルダの扱いを展開／フォルダ表示で切り替え、フォルダに下位サムネイルを重ねる
- リストの列の並べ替え・表示切替・幅、および列ごとのフィルタ
- 単体プレビュー（二度押しまたは Enter。画像はズーム・回転、動画は再生とフレーム送り）
- メタ情報の閲覧（要約＋全タグ、生値／表示値の切替、16 進ダンプ）、
  複数選択時の共通値表示、コピー、JSON / CSV でのファイル書き出し
- 検索: ファイル名／メタ情報（現在のフォルダとブックマークを範囲に選択）
- 類似画像検索（1 枚／複数枚を種に、知覚ハッシュの距離で）と重複候補の提示
- 画面幅に合わせた 3 段階のレイアウト（狭い画面ではメタ情報をボトムシートに）
- 日本語と英語の UI（端末の言語に従う。どちらでもなければ日本語）
- メタ情報の編集（右パネルの「編集」、狭い画面では下部ナビゲーションから）
  - 撮影時刻: 相対シフト、絶対設定、タイムゾーンの読み替え／変換、基準合わせ、
    連番配分、ファイル名とファイル更新時刻からの取り込み、書き込み先の選択
  - 位置: 十進度と度分秒の入力、主対象からの写し取り、削除
  - タグ: 要約とタグツリーから値を直接直す・消す
  - 積んだ操作は当てたらどうなるかを見てから適用し、原本の控えがあれば取り消せる
  - 対象は画像（JPEG / TIFF / PNG / WebP / HEIF）と動画（MP4 / MOV / M4V / 3GP）
- 地図から位置を決める（地図を押して拾い、ピンのドラッグで詰める）。
  位置を持たない対象はトレイから地図へ落として付ける
- 地図の表示範囲で一覧を絞る。撮影順に結ぶ軌跡を出す
- トラックログ（GPX / KML / NMEA）と撮影時刻の突き合わせによる位置の取り込み
- 別のアプリへ渡す（既定のアプリ、アプリを指定、よく使う転送先、OS の共有）
- 選択集合をフォルダへコピー／移動（積んである編集を当てた姿でも書き出せる）
- 地名で場所を探す／座標から地名を引く（既定では止めてある。設定で有効にする）

## キーボード操作（デスクトップ）

| キー | 動き |
| --- | --- |
| ←／→ | 主対象を送る |
| ↑／↓ | 1 行ぶん（サムネイル）／1 件ぶん（リスト・ギャラリー）送る |
| Home／End | 先頭／末尾を選ぶ |
| Enter | 単体プレビューを開く |
| Esc | 選択を解除（プレビュー中は閉じる） |
| ⌘A | すべて選択 |
| ⌘⇧I | 選択を反転 |
| ⌘1〜⌘4 | 表示モードを切り替える |
| ⌘F | 検索欄へ移る |
| ⌘[ ／ ⌘] ／ Alt+←／→ | 戻る／進む |
| ⌘↑ | 親フォルダへ |

プレビュー中は R ／ ⇧R で回し、0 で表示を戻す。

## 開発

```console
$ flutter pub get
$ flutter test
$ flutter run -d macos
```

crowexif を `../crowexif` に置いておく必要がある。

画面の見た目を確かめるときは、決まった順で画面を作っては PNG に撮る入口を使う。
撮る対象が手元に無ければ、位置と撮影時刻を入れた素材を作る入口がある。

```console
$ dart run tool/make_samples.dart <素材の置き場所>
```


```console
$ flutter run -d macos -t tool/capture.dart \
    --dart-entrypoint-args <撮る対象のフォルダ> \
    --dart-entrypoint-args <PNG の出力先> \
    --dart-entrypoint-args <言語 ja|en。省略すると ja>
```
